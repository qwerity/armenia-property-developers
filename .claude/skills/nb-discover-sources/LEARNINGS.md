# nb-discover-sources learnings

## 2026-09-14 (initial build)
- Best multi-developer sources found: myhome.am API, redgroup.am API, novostroiki-yerevan.com sitemap, ar-go.am, bank partner lists (acba, evoca, byblos), construction.am developer catalog, pages.am, developers.am member list.
- Dead ends: 2gis.am (keyed API), list.am (403), spyur.am (scripts get empty results), tunmun.am (refuses connections), ranks.am (5xx), realting.com (no Armenian projects), myrealty.am (2018 data).
- Regions beyond Yerevan/Kotayk/Dilijan/Tsaghkadzor had few online listings (Gyumri, Vanadzor, Jermuk searches mostly empty).
- The user's example of a missed project (4acapital.am) came from a developer site not present on any aggregator — always sweep developer sites, not only aggregators.
